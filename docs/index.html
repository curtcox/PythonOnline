Source, Program input and Auto-run travel together in share links. Opening a link always loads that document and keeps earlier work under More → Resume saved work. Invalid links display an error.

Share includes copy, optional shortening and run-on-open. QR code can generate a link, scan with a camera, or open an uploaded, pasted or dropped image. Long codes offer Save to HashBin. HashBin approval happens on hashbin.org; the editor keeps no credentials.

The main application and Python runtime install offline. More → Make packages available offline installs verified gallery packages separately. PyPI installs still need internet. More → Repair offline copy repairs the main installation.

The default execution sandbox has an opaque origin. Keep files between runs is an explicit local choice; opening or restoring any document turns it off. Shared documents cannot enable it.
